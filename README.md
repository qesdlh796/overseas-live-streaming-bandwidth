## 直播到底吃什么资源

1080P 直播的稳定上行需求是 6–10Mbps，这是持续值，不是端口峰值。VPS 页面标的 200Mbps、1Gbps 是端口速率，跟你能稳定推出去多少是两回事。买之前要问的是保底上行或持续上行，不是端口数字。

比带宽更容易出事的是抖动。业内反复被验证的一条经验是：直播卡顿大多不是带宽不够，而是抖动太大或者出口不干净。公网 BGP 到美西常见 180–250ms，而且抖动大；走 IPLC 专线可以压到 124ms 左右，波动也小。

经常被引用的三个延迟锚点是广港 IEPL 约 3ms、沪日 IPLC 约 25ms、沪美 IPLC 约 124ms。需要说明的是，这组数字是“专线段”延迟，从入口到出口那一段，你本地宽带到入口那一段要另算，别拿 3ms 当成打开网页的体感。

直播卡住的时候，按这个顺序排查更省时间：先看是不是抖动，再看出口 IP 干不干净，最后才怀疑带宽不够。

## 5M 和 10M 到底能带几台手机

两家服务商给出的换算口径不一样，值得并列看。

VDEnet 的写法是：5M 带宽理论上支持 1 台手机直播加 1 台手机运营，10M 支持 3 台手机直播加 2 台手机运营。

弗雷德云按 SLA 承诺写的是：每 5M 推荐连接约 1 台直播设备，20M 约 4 台、30M 约 6 台、50M 约 10 台、100M 约 20 台。

同样 10M，一家给 3 台直播，一家给 2 台。差异来自测试条件和是否留余量，前者是单城市产品页的口径，后者是企业签约页按承诺写的保守值。规划时按 5M 一台算，多出来的当余量，比按 3 台买然后卡在晚高峰强。

WePC 这些套餐没有标“独享带宽”，标的是端口速率和月流量，属于 VPS 规格，不是专线规格。拿 1 核 512M + 200Mbps 端口去对标“10M 独享直播专线”，本身就是两种东西。

## 原生 IP、DNS 和 IP 隔离：三个花钱的误区

第一个误区是带宽越大越好。上面已经说过，卡顿的常见原因是抖动和出口不干净，加大带宽解决不了这两个。

第二个误区是多个账号共用同一个出口 IP。同一 IP 上挂的账号越多，被一起处理的概率越高。

第三个误区是只看 IP 不看 DNS。IP 落在美国、解析却走了别处，平台侧一样能看出来。

自己验的方法不复杂。ipleak.net 可以同时看 IP 归属地和 DNS 落点是不是都在目标国家；scamalytics 查 IP 的风险评分，分数越低越干净。这两步在测试 IP 阶段就该做完，不是付完钱再补。

账号数量上，养号建议 2–5 个共用一条线，直播专线建议 1–3 个，高端专线不设上限，真正要关注的是 IP 是否隔离。

还有两个高频踩坑，跟买哪家没关系，纯属用法问题。一是把线路买回去接在本地宽带上，再用本地网关出去，等于白买。二是同一台设备白天挂养号、晚上开直播，档位混用会让风控记录互相污染。已经调好的配置也别频繁动，很多限流不是线路变差，而是配置被改过。
